# V0.5 原型检查记录

日期：2026-10-23。范围为项目内可点击原型，不是实际 Havenbox 应用或接入验收。

## 检查方式

在 Codex 内置浏览器实际打开 `http://127.0.0.1:8766/index.html`，通过真实表单、按钮、选择器、键盘及页面快照检查。修改后重新加载并复核受影响流程。独立页面无 iframe 和运行时依赖；额外运行 `node doc/prototypes/check.cjs` 验证状态回归。

桌面检查使用 1360 × 960 浏览器视口；窄屏检查使用 390 × 844 和 320 × 844。检查时为系统深色外观，未测试系统浅色、VoiceOver、系统字号放大或真实 macOS 原生控件。

## 发现与修正

1. 计划声明的输出文件名与实际成果名称不一致。将输出名纳入任务数据，计划、成果与回归断言使用同一名称。
2. 整页重绘后焦点落到 `BODY`，确认面板与键盘导航丢失位置。补充动作后的焦点恢复、取消默认焦点、Escape 关闭和返回触发入口，并在实际浏览器复核。
3. 输出校验失败只有文字规格，无法点击触发。增加独立模拟分支，任务显示失败，CLI 记录允许退出码为 0 但校验失败。
4. 清理失败后缺少界面恢复入口。增加模拟关闭工作空间并确认清理；清理未确认前保持活动锁，确认后历史只读、重新检查才能继续。
5. 导出稿依赖可视化宿主包装，原型也未入库。保存源稿与独立构建器，生成无第三方资源的中文页面；CSP 禁止网络连接。
6. 运行记录直接显示内部英文任务状态。改为中文状态，保持技术日志中的退出码和校验结果。

## 复核步骤

1. 刷新回到初始样例，发送并模拟收到回复，核对计划，确认执行，模拟校验通过。
2. 解释负数，再排除负数重新汇总，检查两份成果与合计。
3. 模型与连接中模拟保存凭据、保存草稿、检查；分别测试认证失败和通过。
4. 接入与方案中选择 harness 与 API 模型，模拟组合验证并保存，再新建会话使用。
5. 首次发送先取消授权，再批准；规划中切换其他会话确认不能发送。
6. MCP 重新发现工具，检查空权限不能启用；CLI 启用汇总操作，生成不调用模型的计划。
7. 分别触发调用失败、输出校验失败、停止等待、清理失败与关闭兜底。
8. 打开待恢复历史，核查未知结果，再检查继续或预览摘要重建。
9. 设置中打开清空确认，用 Escape 取消，检查焦点和历史均保留。

刷新仅重置演示数据。任何“通过”“已停止”“已导出”均为显著标注下的模拟，不能作为真实网络、进程或文件操作的证据。
