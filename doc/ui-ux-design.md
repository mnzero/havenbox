# Havenbox MVP UI 设计

版本：V0.6

日期：2026-10-25

依据：[MVP PRD](./product-requirements.md)

## 1. 设计目标

MVP 界面帮助用户完成一件事：导入 CSV，说明任务，确认模型可见的数据和工具计划，检查结果，然后导出。

界面不展示虚拟机、端口、协议和适配器设置。界面必须明确显示数据是否会发送给模型、任务正在做什么，以及停止是否已经完成。

## 2. 页面结构

MVP 有三个页面：

| 页面 | 内容 |
| --- | --- |
| 准备 | 环境状态、固定模型、API Key 状态和连接检查 |
| 任务 | 文件、任务输入、披露确认、计划确认、运行状态和停止 |
| 成果 | CSV 或 Markdown 预览、来源、导出和任务记录 |

顶部状态区始终显示环境状态和活动任务。活动任务存在时，用户不能创建第二个任务。

## 3. 首次准备

准备页按以下顺序显示状态：

1. 检查虚拟机和镜像。
2. 检查固定模型配置。
3. 检查 Keychain 中是否有凭据。
4. 说明连接检查的目标和固定发送内容。
5. 用户启动连接检查。

连接检查不发送文件、文件名、任务文字或历史。界面分别显示凭据存在、端点连接、模型响应和组合资格。任何一项失败时，任务入口保持关闭。

MVP 不提供提供方选择、自定义 Base URL、协议选择、harness 选择或 MCP 管理。

## 4. 任务页

任务页从上到下包含以下区域：

- 文件区：导入、移除和查看校验结果。
- 请求区：输入任务要求。
- 审批区：依次显示数据披露卡和计划卡。
- 状态区：显示当前阶段、最近事件和停止按钮。
- 成果区：显示已验证成果。

### 4.1 文件区

每个文件显示名称、大小、行数、字段和状态。校验失败的文件显示具体原因。界面不显示来宾路径和内部 `FileId`。

用户提交任务后，输入列表冻结。用户改变输入时，旧披露和计划失效。

### 4.2 数据披露卡

首次模型请求前，界面显示以下信息：

- 提供方和模型。
- 任务文字。
- 文件名是否发送。
- 字段名、样例和统计是否发送。
- 最大请求次数和费用状态。

卡片提供 **允许发送** 和 **取消任务**。用户拒绝后，界面不能显示模型已经理解任务或生成计划。

### 4.3 计划卡

计划卡显示以下信息：

- 输入文件。
- 每个工具步骤。
- 筛选条件、分组字段和计算方式。
- 预期成果。
- 资源与时间上限。

卡片提供 **确认并执行** 和 **返回修改**。用户修改任务、文件或规则后，旧计划不能执行。

### 4.4 运行状态

界面使用明确的阶段名称：准备中、等待数据确认、生成计划、等待计划确认、执行工具、生成总结、停止中、已完成、失败、中断或清理失败。

运行期间，停止按钮始终可见。用户点击停止后，按钮变为 **正在停止**。系统确认模型请求和任务进程结束后，状态才变为 **已停止**。

清理失败时，界面保持忙碌，并显示 **关闭工作空间**。界面不能允许用户启动新任务。

## 5. 成果页

成果页列出文件名、类型、大小、生成步骤、输入来源和校验状态。未完成或结果未知的成果默认不选中。

CSV 使用分页表格预览。大单元格显示裁剪标记。Markdown 禁用 HTML、脚本和远程资源。文本移除终端控制序列。

导出流程如下：

1. 用户选择一个或多个成果。
2. 用户选择宿主目标位置。
3. 界面列出文件名冲突和 CSV 公式风险。
4. 用户确认覆盖或选择新名称。
5. 界面逐项显示成功、失败或结果未知。

## 6. 历史与重置

任务页提供只读任务记录。记录包含请求、披露决定、计划、状态、成果和错误。MVP 不支持搜索、重命名、归档、删除单个任务或继续对话。

重启后，已完成任务和成果可以打开。未完成任务显示为中断。界面不提供自动继续或重试按钮。

重置需要二次确认。确认文案明确说明会删除工作空间内的输入副本、任务记录和成果，但不会删除宿主原件、已导出文件、运行时或 Keychain 凭据。

## 7. 错误与空状态

每个错误显示安全文案、发生阶段和可执行的下一步。详细诊断通过引用打开，不在主界面显示完整请求、CSV 内容或密钥。

必须覆盖以下状态：

- 缺少或损坏的 VM 资源。
- 缺少 Key、认证失败、额度不足、TLS 错误和网络中断。
- CSV 编码、表头、大小和格式错误。
- 规则不明确。
- 工具拒绝、超时、异常退出和结果校验失败。
- 磁盘不足、导出冲突和清理失败。
- 没有输入、没有任务和没有成果。

## 8. 可访问性

所有操作支持键盘。焦点顺序遵循页面顺序。数据披露和计划确认不能只靠颜色区分。状态改变通过辅助技术播报，但流式文本不逐字播报。

界面支持系统字号、长文件名和窄窗口。按钮在任务状态不允许操作时保持可见，并说明禁用原因。

## 9. MVP 验收

UI 验收必须使用真实模型、真实 VM 和真实 CSV CLI。可点击原型只检查布局和文案。

三个目标用户需要完成以下操作：

1. 配置 Key。
2. 导入 CSV。
3. 说明汇总和异常筛选任务。
4. 判断并批准模型发送范围。
5. 检查并批准执行计划。
6. 在运行中使用停止。
7. 重新执行任务并预览成果。
8. 导出成果。

每位用户都必须能回答哪些数据发送给模型，以及哪些操作发生在隔离环境中。
