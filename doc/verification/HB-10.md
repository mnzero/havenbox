日期：2026-10-24。独立候选开发，不提交、不委派、不修改 HB-04/HB-06 证据，不实现 HB-11 或之后业务，发布资格保持关闭。

## 实现与边界

实际目录 `Sources/HavenboxCore/Workspace{Store,Database,Schema,Transactions}.swift` 沿 HB-09 工程，而非规划的 `host/WorkspaceStore/`。单 actor、私有 SQLite 连接、进程级独占 flock、WAL/FULL/外键、显式 checkpoint；短事务绑定状态和事件，持久命令 ID + SHA-256 输入身份去重。事件计数器独立于可删除历史，不复用已删除序号。公开接口仅宿主领域调用，没有公开任意 SQL、凭据、模型请求或工具执行能力。

§6 表落地，包括 28 张关系/维护表（含命令与事件计数器）；CHECK/FK/UNIQUE、执行审批与任务/回合/计划摘要复合 FK、源会话 SET NULL、文件引用 RESTRICT、不可变快照和 deleting 文件引用/pin 禁止触发器。首次披露不要求任务。迁移先查活动槽与磁盘，backup API 完整备份，再记录维护状态、事务迁移；失败关闭可写连接并重开 READONLY，重启仍识别未完成维护记录。迁移 API 内部可见，当前没有虚构 v2 产品迁移。恢复需宿主先核实旧进程结束，才显式标记中断并撤销旧审批；不自动发送请求、不重放工具、不释放未经核实的 pin。

父目录要求本账号所有、0700、非符号链接；数据库0600、NOFOLLOW，错误不包含 SQL/用户绑定文本。应用账号或 root 的恶意进程不在 flock 防御范围；这是协作宿主实例互斥，不声称防御同 UID 主动删除锁文件或任意修改数据库。宿主目录祖先由应用信任，不承诺抵抗同 UID 的并发目录替换。备份目标必须新文件；失败残留不可当成功备份。未实现跨盘业务迁移、GC 调度、导出、VM、UI 接线或自动恢复授权。
