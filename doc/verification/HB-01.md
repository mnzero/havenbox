## 后续证据格式与未验证边界

`probeRecord.requiredFields` 定义后续探针的记录字段。每次记录实际候选 ID、测得版本、适配器版本、模型 ID 与协议、工具入口、来源 URL 或 commit、制品 SHA-256、许可证、完整可重跑命令、环境、预期、实际、退出码、观测、结果、证据路径、时间及未验证边界。不适用字段明确填 `not-applicable` 并解释原因，不能填虚构版本或哈希。

结果使用 `pass`、`fail`、`blocked` 或 `unknown`。单次探针结论只覆盖实际运行的版本与场景。文档声明、版本命令成功或进程启动均不能产生组合通过证据；不同 harness、模型与工具方式不得互相推断通过。

本次未验证最低系统版本、实际 16 GiB 参考设备、工具链候选发行、安装包来源及哈希、许可证分发条件、无网 VM、失联清理、真实模型调用、MCP 与 CLI 一致性、产品错误处理、注入隔离、停止、重启、多轮和授权出口。上述事项由 HB-02 及后续任务处理。HB-01 交付不改变任何产品能力或组合的未测试状态。
