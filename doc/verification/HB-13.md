日期：2026-10-24。基于工作区 HEAD `b7d89cf3aa78261127998b956aadb8c04ca8817f`，独立写者，无委派、无提交、无下载或新增第三方依赖。结论：**Rust 引擎功能与资源拒绝路径通过**；不是 VM、harness、MCP/CLI 或产品执行资格通过。

## 实现与依据

读取 AGENTS、HB-13、PRD §9、技术设计 §5.6、HB-01 证据、全部九个 CSV 与 `expected-results.json`。新增 [Rust crate](../../guest/csv-engine/README.md)，加入现有 Cargo workspace/lock。仅使用标准库，沿用已固定 Rust/Cargo，无新增依赖来源、许可证或制品下载需要审核。

五工具是实际 Rust 函数：`inspect_csv`、`concat_csv`、`filter_rows`、`aggregate_csv`、`write_report`。工具参数采用 Rust 枚举及 [声明式 schema](../../guest/csv-engine/schema.json)，无路径、表达式解释器或任意 SQL；本任务没有提前实现 MCP/CLI JSON 适配。输入由可信调用方提供字节并取得私有构造的 FileId，原字节不修改。输出只在成功后登记，失败不新增成果/事实；事实持有输入来源、操作规则、行数、金额及成果引用，报告仅引用实际 FactId，不接受模型生成数字。

金额为 checked i64 cents，scale=2、16位整数，与候选 manifest 语义一致；非法值、精度和中间/最终溢出明确拒绝。CSV 支持严格 UTF-8/BOM、引号和引号内换行，拒绝重复/空表头及不齐行。重复键比较原始字符串元组，包括空字符串，不 trim 或 casefold，两种模式保持输入顺序；聚合按键元组字典序输出，组数与参与行数单列。

## 资源与真实 spill

输入数/字节、行列、单元格、预览、序列化输出、总内存估算、聚合工作内存及组数均有界，具体默认值与取舍见 crate README。超过聚合工作内存时，可信调用方提供的 `Scratch` 私有目录能力启用磁盘映射；不把路径暴露给五工具。逐记录读取/更新，追加前校验累计磁盘字节，单键超过工作内存立即拒绝。磁盘文件 create_new 后立即 unlink，后续仅用句柄，返回/错误/取消时关闭；不会删除目录或无关文件。

强制 128 字节工作预算的真实临时目录测试比较内存与 spill 的聚合和两种重复筛选结果，覆盖复合键、空值和换行。1字节磁盘预算拒绝、目录失效 IO 错误、非法数值发生于写入之后及活动扫描取消均无成功部分成果，临时目录无残留；取消用例保留 unrelated 哨兵文件。外部映射为 O(行×组) 线性扫描，优先正确性与有界空间，不声称高吞吐。取消逐行及磁盘记录检查，未宣称解析器中每字节取消。

内存限制是保守逻辑预算，不等同于 allocator/RSS 硬隔离；新增 `allocator_regression` 独立 integration test 二进制（单测试进程）：GlobalAlloc 包装 System，Atomic 开关仅覆盖 filter 调用窗口，最大单次分配计数路径不做格式化或分配；1MiB Text 参数和输入在窗口外构造，8192 字节预算下实际最大单次分配为 0 字节，结果为 `memory_limit`，且无新增成果/事实。该测试证明逻辑预检未先 materialize 2MiB Debug 文本，不宣称 RSS 硬限额。输入和最终输出仍在总内存预算内。将私有源码副本的旧 Debug 估价调用临时恢复后运行同一测试，实际最大单次分配为 2,097,152 字节并失败；主工作区修复版通过。解析前保守预留可能提前拒绝小于50MiB的合法大文件，这是清晰资源失败而非截断。私有目录及其祖先不可被替换由可信调用方保证，真实 worker namespace/cgroup 和恶意目录竞态隔离尚未验证。
