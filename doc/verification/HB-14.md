## 四项边界

1. `CallPermit` 完全私有，无 public 构造、反序列化或 issue。公共 `Approval` 只是请求数据；`HostVerifier.consume` 必须由可信 supervisor 注入，原子核对宿主记录/证明、撤销与全局一次性 call ID。生产仅提供总是拒绝的 `UnconnectedHost`，测试 issuer 仅在 `cfg(test)` 私有模块。绑定 issuer、callId、task/session/provider/model/tool revision、planDigest、step、epoch、argumentsDigest、templateDigest、permissions、limits、期限与预期成果。Dispatcher 另存本实例已消费 call ID，执行/解析失败不返还许可；跨实例防重放仍由宿主注册表负责。SHA-256 仅完整性，不是宿主认证。
2. `Template.load` 实际读取并逐字节匹配编译期受审 JSON 快照（包括空白变化也拒绝），不是通用动态 JSON schema 解释器。唯一批准 schema 固定为 FileId、枚举 csv、1–200 整数，固定 argv 前缀/选项；路径仅来自可信 FileId staging 映射并核对 HB13 engine 内容，不接受模型路径、shell 或表达式。环境清空且模板环境为空；不同模板即使 executable/cwd 相同也拒绝。真实只读 staging mount/TOCTOU 隔离仍 blocked。
3. stdout/stderr 非阻塞交替读取，每次最多 4096 字节，合并累计上限在追加前拒绝；使用 Instant deadline，父退出仍须双管道 EOF，否则截止失败。取消/超时/错误/正常退出统一 killpg，250ms 有界轮询直接子进程回收和进程组消失，无法确认则 `cleanup_unconfirmed`，不伪造成功。结构化诊断保存 code/status/两流已保留字节数/cleanupConfirmed，不泄露原始 stderr 内容。未实现 Linux subreaper/cgroup，不能声称已 wait 所有后代或阻止 setsid 逃逸。
4. 退出 0 后校验宿主批准的内容 SHA-256、CSV schema/header 与完整行数；provenance 保留完整批准绑定及输入 FileId。候选结果只在临时私有 HB13 Engine 完整注册和 inspect 后发布 FileId/FactId，任何失败丢弃整个临时 engine，不发布半成品事实。受 hash 验证的原始 stdout 保存在 Published 私有字节缓冲区，`csv_bytes()` 只返回其副本；HB13 Engine 仅用于解析和生成事实，不将规范化序列化字节作为已批准成果。CRLF、UTF-8 BOM 和冗余引号均原样保留，不重算 hash 掩盖字节变化，`sha256(csv_bytes()) == content_hash == provenance.result_hash`。报告只能通过 HB13 write_report 引用该事实。该边界是 CSV inspect 成果发布，不是持久 ArtifactVersion/共享成果库或真实 CLI 全链；预期结果 hash 必须来自可信批准记录，不允许工具自证。非零状态在结果校验前保留独立 exit 诊断。
