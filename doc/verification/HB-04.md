# HB-04 Kimi CLI 接入契约探测

日期：2026-10-24。本轮修复 Kimi Review 的探针隔离与 fail-closed 缺陷，未提交 commit。

## 结论

**探针安全回归通过，真实 Kimi 协议验证仍为 blocked。** 默认网络关闭时，CLI/ACP 版本检查也不启动任何外部进程；本次结果为 schema=2、overall=blocked、network_allowed=false、business_data_used=false、home_mode=0o700，五类协议事件均 blocked。当前未实现真实 ACP 请求适配器，也没有执行联网请求。

旧探针曾从 PATH 发现 CLI 2.2.0，且 ACP `--version` 返回不支持选项；这些是修复前的历史观察，不是当前默认运行的结果。当前固定部署位置为 `/usr/local/bin/kimi`，不再使用宿主用户目录中的 CLI，也不在运行时发现或安装可执行文件。

## 修复边界

- 固定 executable `/usr/local/bin/kimi`，固定 argv 为 `--version` 和 `acp --version`；无 shlex、shell 命令字符串或环境指定 adapter。`KIMI_CLI`、`KIMI_ACP`、`KIMI_CODE_HOME` 只要存在就明确 blocked，包括空字符串，不记录其值。直接空命令同样 blocked。
- 网络许可检查位于进程启动之前；默认模式的版本检查和协议事件全部 blocked。`KIMI_ALLOW_NETWORK=1` 是启动许可，并非 OS 网络沙箱，当前仅允许固定版本检查。
- 探针在解析后的系统 `/tmp` 下通过独占 mkdtemp 自建私有目录，显式 chmod 0700，验证 owner、目录类型、权限和符号链接组件，退出时删除。拒绝用户指定共享目录或符号链接，不改变它们的权限。忽略调用者 TMPDIR。
- 子进程环境从空字典构建，只传固定 PATH/LANG 和指向私有目录的 HOME、KIMI_CODE_HOME、TMPDIR、XDG_CONFIG_HOME、XDG_CACHE_HOME。不会继承凭据、代理、PYTHONPATH 或 loader 环境变量；cwd 也设为私有目录。
- 只记录固定 profile 与命令 SHA-256 摘要，不记录/执行用户命令输入。stdout/stderr 合计最多捕获 16 KiB 原始字节，默认 20 秒超时，超限或超时终止进程组。输出清理常见敏感字段、bearer token 和环境中的已知 secret 值；异常仅记录类型，不输出异常文本。任意无标签未知秘密无法保证识别，因此仍禁止业务私密数据进入探针。
- 请求结构中的 prompt、工具建议和停止意图只是固定元数据，未执行工具、业务文件操作或子 Agent，也没有虚构 ACP 帧。

以上全部通过。探针 JSON 时间为 `2026-10-24T06:27:24Z`，CLI/ACP 均返回 `blocked: network disabled; no external commands executed`。回归覆盖：网络关闭零 Popen 调用；CLI/ACP 注入、空字符串及环境覆盖拒绝；空/未批准命令拒绝；共享目录和符号链接拒绝且不被修改；私有目录 0700 与退出清理；stdout/stderr 脱敏和子进程环境净化；捕获上限及超时清理；异常文本不泄露秘密。进程捕获测试只启动测试自有 Python helper，不执行 Kimi 或网络请求。
