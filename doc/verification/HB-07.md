# HB-07 本地模型候选验证

日期：2026-10-24。范围是基于已通过 HB-02 真实 ARM64 VM 的本地模型候选探针实现；不修改 HB-01、HB-02、HB-03。探针位于 [experiments/local-model](../../experiments/local-model/)，只读取本地已有文件和运行时，不下载、安装或云端回退。

## 结论

**blocked：当前工作区没有可验证的本地模型运行时、模型制品或许可证记录。** 因此没有选择模型组合，也没有把 `candidate-local-csv` 标为通过。探针明确要求运行时版本、精确模型 ID、量化、模板、工具 schema、SHA-256、许可证和离线隔离证据；缺少任一关键项会产生 `blocked`、`unknown` 或 `fail`。

## 可复现探针

```sh
set +e
experiments/local-model/run.sh --offline > /tmp/hb07-record.json
probe_status=$?
set -e
python3 -m json.tool /tmp/hb07-record.json >/dev/null
printf 'probe_exit=%s\n' "$probe_status"
```

本次输出 `probe_exit=2`，JSON 可解析；记录中的运行时、模型、许可证和离线声明检查均为 `blocked`，工具 schema 和模板为 `unknown`。`--offline` 与 `HB07_NETWORK_DISABLED=1` 只能使 `offlineDeclaration` 前置声明检查通过；物理断网须独立证明，实际离线运行始终未验证。

准备真实候选后，使用：

```sh
HB07_NETWORK_DISABLED=1 experiments/local-model/run.sh \
  --candidate-id local-llama-candidate \
  --runtime llama-server \
  --model /absolute/path/model.gguf \
  --license Apache-2.0 \
  --protocol local-http --tool-entry-point mcp \
  --tool-schema /absolute/path/tool-schema.json --offline \
  --min-memory-gib 8 --output /tmp/hb07-record.json
```

模型旁边必须存在 `<model>.<suffix>.json`，且包含 `modelId`、`quantization`、`template`、`license`、`sourceUrlOrCommit` 和 `runtime`。已移除无用途的 `--source`，传入会被拒绝，来源只读取元数据。GGUF 文件会校验 `GGUF` magic；magic 错误为 `fail`，magic 正确不证明制品完整或可加载。探针按块计算模型 SHA-256，记录实际运行时版本命令、环境、内存和 GPU 查询结果。GPU 信息只作为观测，不能单独产生通过；工具调用必须提供实际 schema 路径，运行时特定的执行仍需后续真实调用验证。

## 检查项与边界

| 检查 | 规则 |
| --- | --- |
| 运行时 | 仅接受本地 `llama-server`、`llama-cli`、`ollama` 或 `llamafile`，实际版本命令失败即 `fail` |
| 模型 ID/量化/模板 | 只接受相邻元数据中的精确字段，不从文件名推断 |
| 制品完整性 | 记录 SHA-256；GGUF magic 错误为 `fail` |
| 工具 schema / 调用 | 未配置 schema 为 `unknown`；指定路径不存在为 `blocked`；JSON 或结构不一致为 `fail`；实际调用始终为 `unknown` |
| GPU | 记录 macOS `system_profiler` 结果；不自动声称 GPU 可用 |
| 物理断网 | 外部隔离声明与 `HB07_NETWORK_DISABLED=1`、`--offline` 只使前置声明检查通过，否则为 `blocked`；真实离线运行始终为 `unknown` |
| 资源 | 记录主机内存；低于 `--min-memory-gib` 为 `fail` |
| 许可证 | 必须显式传入或由元数据提供；缺失为 `blocked` |
| 失败语义 | 缺失/加载失败/schema 不支持/资源不足不会静默降级或云端回退 |

机器输出显式包含 `scope=preflight-only`、`runtimeValidation=unverified`。`preflightResult`、`actual.preflightCombination`、`actual.toolSchema` 可为 `pass`；总结果遇到前置失败或阻塞时保留 `fail`/`blocked`，其余情况为 `unknown`，退出码均为 2。无效制品即使带有正确 magic、完整元数据、schema、版本命令与环境声明，也不能宣称真实组合验收通过。

真实模型加载、GPU 执行、离线运行、工具调用及组合验证未执行，对应 `actual.modelLoading`、`gpuExecution`、`offline`、`toolCalling`、`combination` 始终为 `unknown`。真实模型加载、模板渲染、工具调用、GPU 执行和 HB-02 VM 内的无网运行必须另行执行并保存证据，仅重跑此前置探针不能完成验收。
