## 探针与固定策略

交付文件为 [experiments/vm/probe.py](../../experiments/vm/probe.py)、[run.sh](../../experiments/vm/run.sh) 和 [README.md](../../experiments/vm/README.md)。`launch` 固定 `-M virt`、`-accel hvf`、`-cpu host`、`-nodefaults`、只读 root image、持久 virtio data disk、serial stdio，并显式加载 kernel/initramfs 与 guest payload；命令不包含 `-nic`、`-netdev`、QMP 或宿主目录共享。控制、文件分块、推理串流使用长度前缀 JSON frame；每帧限制 1 MiB，文件分块限制 256 KiB，强制 epoch、消息类型、控制动作、非负整数 offset、非空且限长 transfer_id 和传输取消状态校验。内存、CPU、文件类型、后缀和容量也在启动前校验。

探针启动或 README 声明不构成安全边界证据。`self-test` 现在覆盖协议解析和真实 OS pipe 上的阻塞读取取消，输出明确为 `vm_boundary: unverified`。

## 测试结果

### 协议最小通道

命令：`experiments/vm/run.sh self-test`
退出码：`0`
实际输出：`{"result": "passed", "scope": "frame-channel-and-cancellable-pipe", "vm_boundary": "unverified"}`
证据：命令 stdout；实现位于 `experiments/vm/probe.py`。

覆盖并实际拒绝：超长 frame、超大 file chunk、未知消息类型、跨 epoch、截断 frame、非法控制动作、负数和布尔 `offset`、空 `transfer_id`、取消控制帧导致后续传输拒绝。阻塞读取使用真实 `os.pipe()`，取消事件在无输入时唤醒轮询并使 reader 返回 `read cancelled`；这验证的是宿主通道读取行为，不是来宾隔离或真实 VM 文件服务。推理串流使用同一有界 frame parser，尚未连接真实模型。

### 真实 VM 启动尝试

命令：`experiments/vm/run.sh launch --image evidence/hb-02/missing.img --data evidence/hb-02/missing.raw --kernel evidence/hb-02/missing.kernel --initrd evidence/hb-02/missing.initrd --payload evidence/hb-02/missing.payload`
退出码：`3`
实际 stderr JSON：`{"result":"blocked","reasons":["[Errno 2] No such file or directory: 'evidence/hb-02/missing.img'","QEMU unavailable: [Errno 2] No such file or directory: 'qemu-system-aarch64'","qemu-img unavailable or invalid output: [Errno 2] No such file or directory: 'qemu-img'"],"qemu":"qemu-system-aarch64"}`。缺少 guest artifacts 时探针 fail-closed；当前环境也没有 QEMU 或 qemu-img。

这是 fail-closed 的资源缺失结果，不能算 VM 通过，也没有模拟启动或伪造网络测试。由于没有 QEMU、ARM64 guest image、kernel/initramfs 和持久数据盘，以下均为 **blocked/unknown**：

- 真实 VM 无虚拟网卡；
- 无宿主目录共享；
- 来宾不可达 QMP；
- 重启后测试对象保留；
- 来宾不可访问宿主测试文件；
- 互联网与局域网不可访问；
- 真实 VM 内的超长帧、未知消息、跨 epoch、取消中的阻塞文件传输行为。

## 未验证边界

本探针固定了预期 QEMU 参数并能在资源缺失时明确失败，但无法替代 guest-side 观测。后续具备 QEMU/HVF、经过校验的只读 ARM64 镜像、可写持久 raw 数据盘和来宾测试 payload 后，应启动真实 VM，记录 QEMU 版本、完整脱敏命令、设备清单、guest `ip link`/mount/QMP 可达性、重启前后测试对象校验和、宿主文件/互联网/局域网探测结果及每项退出码。当前报告没有把任何未执行项标为通过，也没有修改 HB-01 文件或实现正式运行时。
