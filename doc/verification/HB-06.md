## 实际宿主协议观察

原始结果：[host-observation.json](../../experiments/harness/dsh/host-observation.json)。真实 npm launcher、真实 SDK；没有替身 dsh。模型路由显式设 `deepseek-official/deepseek-chat`，base URL 固定 `http://127.0.0.1:1`，只给假 sentinel key；没有发送 session/prompt，没有启动本地模拟模型端点。

| --- | --- | --- |
| initialize | `deepseek-harness-sdk-runtime` / `0.0.1` | 真实握手成功，无模型推理 |
| session/working-directory/get | 新 session 返回独立 workspace | 原生惰性会话创建（非模型任务） |
| session/wait | `{}` | 空闲会话可等待 |
| 未知 session wait | -32603 / unknown SDK session | 错误可关联请求 ID |

| shutdown | `{}` | SDK owned sessions 释放；不是进程退出 |

## 尚未通过的边界及可行动方案

1. **真实 VM 安全边界 unknown**：本次在宿主隔离临时目录运行，不是 VM；HOME/env 清理不是权限隔离。下一步把固定 Linux arm64 制品离线打包送入 HB-02 无网卡 VM，经 HB-03 生命周期控制跑相同序列；验证无共享目录、无直连、通道取消和子进程清理。本次未使用 Darwin 制品冒充来宾可用。
2. **审批 unsupported/待开发**：rc.3 SDK protocol 未提供审批桥；sdk-minimal 原始树是 `danger-full-access`，含 persistent shell/read_image/working_directory，不能给予普通用户任务资格。需要受审 profile/plugin 补丁或明确冻结另一个含审批协议的 commit，重新验证；不能只设置不存在的 `approvalRequests=true`。
3. **模型/事件/工具/活动取消 unknown**：本次未 prompt，不证明 token streaming、模型兼容、工具审批或活动 turn 停止。下一步可用显式标注的本地测试端点验证协议事件/取消；真实联网模型必须先授权，不能把 mock 当模型验收。
4. **遥测/隐式外联 unknown**：源码 minimal 排除 base telemetry，但没有真实 VM firewall/抓包证明。baseURL 指向 loopback 防止本次配置到公共模型，不能宣称宿主整体禁止外联。自动 compaction/retry 仍存在，需受管路由与明确预算。
5. **恢复 unknown**：原生 resume 存在，当前仅验证 missing error。宿主应从校验历史重建并重新授权；不得自动重放工具或旧审批；后续验证真实持久化恢复/中断尾部修复。
6. **制品来源边界**：已核对 tag、npm integrity 与运行树，但未证明 npm 字节可由 tag bit-for-bit 构建；若交付需要更强溯源，使用固定源码/pnpm lock 在隔离构建环境重建，生成 SBOM 与制品签名。GitHub API 403 不阻碍当前 npm 路径。
